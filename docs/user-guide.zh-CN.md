# 使用指南（Cong）

Cong 是面向港口和物流现场的集装箱照片记录服务。
它按集装箱编号整理照片，减少发送、分类和确认照片的工作。

## 1. 登录
1. 打开应用 URL。
2. 按 `登录`，通过 Cognito 登录。
3. 首次使用时，输入显示名称。

## 2. 房间
房间按企业或事业所单位使用。

### 创建房间
1. 在房间画面输入公司名或事业所名。
2. 按 `创建房间`。
3. 创建后会进入该房间。

注意:
- 每位用户只能创建一个房间。
- 成员可通过邀请 URL 加入。
- 邀请 URL 有效期为 7 天。

## 3. 集装箱
Cong 将文件夹作为集装箱记录使用。
请将集装箱编号登记为文件夹名。

示例:
- ABCU1234567
- MSCU9876543

未来计划支持 OCR 自动输入。

## 4. 照片文件夹
照片文件夹用于记录集装箱照片。
请为每张照片添加标签。

推荐标签:
- 集装箱编号
- 进场
- 封条
- 损伤
- 出场
- 其他

也可以为每张照片留下评论。

## 5. 任务文件夹
任务文件夹用于拍摄请求和防止漏拍。

示例:
- 集装箱编号
- 封条
- 左侧面
- 右侧面
- 损伤位置

可预先准备需要拍摄的照片，然后由现场成员上传。

## 6. 照片和评论
照片可以单张或批量上传。
拍摄后可以添加标签。

评论示例:
- 封条有破损
- 左侧面有凹陷
- 出场完成

## 7. 搜索
使用搜索标签页，可以按标签、搜索词和范围查找已保存照片。
可以在当前集装箱内搜索，也可以在当前房间内搜索。

## 8. 导出
可按集装箱导出 PowerPoint。
可用于制作集装箱报告资料。

推荐顺序:
- PDF 适合稳定查看
- 轻量 PPT 适合重视文件大小时使用
- 高画质 PPT 适合 PC 确认或正式提交

## 9. 权限
管理员管理房间、成员和文件夹。
成员登记照片和评论。
