# 利用者向けガイド（Cong）

このガイドは、港湾・物流の現場でCongを使う方向けの手順です。
Congはコンテナ写真をコンテナ番号ごとに整理し、送信・仕分け・確認業務を減らすサービスです。

## 1. ログイン
1. アプリURLを開きます。
2. `ログイン` を押してサインインします。
3. 初回は表示名を入力します。

## 2. お部屋
お部屋は企業・事業所単位で利用します。

### 2-1. お部屋を作る
1. お部屋画面で会社名や事業所名を入力します。
2. `お部屋を作る` を押します。
3. 作成後、そのお部屋に入室します。

注意:
- 1ユーザーが作成できるお部屋は1つです。
- メンバーは管理者から受け取ったURLで参加します。
- 招待URLは7日間有効です。

### 2-2. お部屋を切り替える
1. 画面上部の `現在のお部屋` を開きます。
2. 入室したいお部屋を選びます。
3. 確認ダイアログで `OK` を押します。

## 3. コンテナ
Congでは、コンテナ番号を記録単位として登録します。
登録時に `通常記録` または `クエスト記録` を選択してください。

例:
- `ABCU1234567`
- `MSCU9876543`

将来的にはOCRによる自動入力にも対応予定です。

## 4. 通常記録
通常記録では、コンテナに関する写真を自由に追加します。

写真にはタグを付けられます。

タグ:
- コンテナ番号
- 搬入
- シール
- 損傷
- 搬出
- その他

写真ごとにコメントも残せます。

## 5. クエスト記録
クエスト記録は、必要な写真を事前に依頼するために使います。
撮影漏れ防止に利用します。

依頼例:
- コンテナ番号
- シール
- 左側面
- 右側面
- 損傷箇所

## 6. 写真
写真は単体または一括でアップロードできます。
アップロード時に写真ごとのタグを選択します。写真名は `コンテナ番号_タグ名_3桁連番` の形式で自動生成されます。

## 7. コメント
写真ごとにコメントを残せます。

例:
- シール破損あり
- 左側面にへこみあり
- 搬出完了

## 8. 検索
`検索` タブでは、保存済み写真をタグ、キーワード、検索範囲で絞り込めます。

- `このコンテナ`: 選択中のコンテナ内を検索
- `このお部屋`: 現在のお部屋にある閲覧可能なコンテナを横断検索
- キーワード: コンテナ番号、コメント、投稿者を検索

## 9. 出力
コンテナ単位で次の形式を出力し、コンテナ報告資料の作成に利用できます。

- PDF（推奨）
- 軽量PPT
- 高画質PPT

クエスト記録では、完了済みクエストの写真が出力対象です。

## 10. 権限管理
管理者は、お部屋管理・メンバー管理・コンテナ管理を行います。
メンバーは、許可された範囲で写真・コメント・クエストを登録します。投稿の作成者と管理者は削除操作を行えます。
