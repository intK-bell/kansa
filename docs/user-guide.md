# 利用者向けガイド（Cong）

このガイドは、港湾・物流の現場でCongを使う方向けの手順です。
Congはコンテナ写真をコンテナ番号ごとに整理し、送信・仕分け・確認業務を減らすサービスです。

## 1. ログイン
1. アプリURLを開きます。
2. `ログイン` を押してサインインします。
3. 初回は表示名を入力します。

## 2. お部屋
お部屋は企業・事業所単位で利用します。

### 2-1. お部屋を作る
1. お部屋画面で会社名や事業所名を入力します。
2. `お部屋を作る` を押します。
3. 作成後、そのお部屋に入室します。

注意:
- 1ユーザーが作成できるお部屋は1つです。
- メンバーは管理者から受け取ったURLで参加します。
- 招待URLは7日間有効です。

### 2-2. お部屋を切り替える
1. 画面上部の `現在のお部屋` を開きます。
2. 入室したいお部屋を選びます。
3. 確認ダイアログで `OK` を押します。

## 3. コンテナ
Congでは、フォルダをコンテナ単位で利用します。
コンテナ番号をフォルダ名として登録してください。

例:
- `ABCU1234567`
- `MSCU9876543`

将来的にはOCRによる自動入力にも対応予定です。

## 4. フォトフォルダ
フォトフォルダでは、コンテナに関する写真を記録します。

写真にはタグを付けられます。

推奨タグ:
- コンテナ番号
- 搬入
- シール
- 損傷
- 搬出
- その他

写真ごとにコメントも残せます。

## 5. クエストフォルダ
クエストフォルダは、必要な写真を事前に依頼するために使います。
撮影漏れ防止に利用します。

依頼例:
- コンテナ番号
- シール
- 左側面
- 右側面
- 損傷箇所

## 6. 写真
写真は単体または一括でアップロードできます。
撮影後にタグを付けて、コンテナ番号ごとに整理します。

## 7. コメント
写真ごとにコメントを残せます。

例:
- シール破損あり
- 左側面にへこみあり
- 搬出完了

## 8. 出力
コンテナ単位でPowerPoint出力できます。
コンテナ報告資料の作成に利用できます。

## 9. 権限管理
管理者は、お部屋管理・メンバー管理・フォルダ管理を行います。
メンバーは、写真登録・コメント登録を行います。
